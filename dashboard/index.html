Architecture

Clients talk only to FastAPI. The v2 graph can retrieve and propose. Classic backtest and realtime share TradeExecutor and SQLite.

Classic dashboard

  • Save a named strategy instance (Bollinger for backtest, Kernel for backtest and live ticks).
  • Run a historical backtest; orders and ending NAV land in SQLite.
  • Start a virtual or real deployment so websocket ticks drive the same live strategy.

V2 investment graph

  1. Research retrieves fixture 10-K / 10-Q / news chunks (hybrid BM25 + dense search). The summary must be grounded in those excerpts.
  2. Quant runs Kernel momentum and Bollinger band logic and emits structured signals, not broker calls.
  3. Risk scores concentration, VaR, drawdown, circuit-breaker returns, and grounding.
  4. Adjudicator merges those inputs into one order proposal or a typed reject.
  5. Policy is deterministic: about 5% NAV per name, stop-loss, VaR, drawdown, cash. A model cannot override this.
  6. HITL always pauses before execute_order. Approve or reject from the queue.
  7. Execute is the only node allowed to call TradeExecutor, and only after policy is replayed.

What approve does

Approve runs immediately. It does not wait for the next trading day and does not place an AMO / GTD order.

  • Virtual writes a SQLite paper fill now. Angel is not contacted.
  • Real calls Angel placeOrder now as LIMIT / INTRADAY if the session is live. A closed market is a broker reject, not a next-day queue.
