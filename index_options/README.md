# TRADING BOT

This trading bot is specifically designed for bank nifty options trading strategies. 

### Goals
- Build hypothesis and backtest strategies in jupyter notebook
- Test strategies with real-time data from smartapi, create virtual orders and analyse orders and portfolio
- Analyze portfolio and manage risk
- Do real trading

### MVP
- gamma scraping strategy
- generalize back testing, virtual trading
- Portfolio dashboard, virtual orders analysis, real orders analysis
